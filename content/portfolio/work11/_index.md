# Microbenchmarking GPUs

As part of the MIT CSAIL Database Group. Microbenchmarking newer
generations of NVIDIA GPUs, including GeForce GTX Titan X.

Modeling page table structure and TLB misses. Developing and optimizing
performance of GPU-based database algorithms. Worked with Anil Shanbhag
and advised by Professor Sam Madden.

Used CUDA and C++.

  - [Code](https://github.com/lizziew/cuda_playground)

(Work mostly in private repo.)
