# N Chainz

A high performance, decentralized cryptocurrency exchange written in Go.

Worked with Nicholas Egan and Ryan Senanayake. N Chainz’s features
include block generation, limit orders, and the ability to trade a base
token with another token. Our team was one of the winners in the Binance
Dexathon competition.
