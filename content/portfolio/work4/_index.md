# Firebase backend plugin for Mavo

As part of the MIT CSAIL Haystack Group. Implemented Firebase backend
plugin for Mavo web framework.

Mavo adds data editing and spreadsheet-style formulas that permit the
construction of full-fledged applications in a single HTML document.
Worked with Lea Verou and advised by Professor David Karger.
